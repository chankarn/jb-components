# jb-components

คอมโพเนนต์ UI กลางที่ย้ายมาจาก CP-Meiji Non-Campus (อ่านอย่างเดียวจากต้นทาง)
Stack: Next.js 15 · React 19 · Tailwind 3.4 · framer-motion · lucide-react · i18n ไทย/อังกฤษ (ย้าย `src/lib/i18n` มาทั้งโฟลเดอร์)

```bash
npm run dev     # http://localhost:3400 (หน้า Gallery)
npm run build
```

## ข้อตัดสินใจ
- ไม่ย้าย `LangSwitch` (ผูกกับ `POST /api/lang` + cookie ของต้นทาง) ใช้ `PillSwitch` ต่อกับกลไกสลับภาษาของแอปปลายทางเอง
- hydration error #418 ที่เคยเห็นตอนทดสอบ ไม่ใช่บั๊กของโค้ด: ตรวจซ้ำบนพอร์ตใหม่แล้วไม่มี ที่เห็นมาจาก origin `localhost:3200` ซึ่งใช้ร่วมกับโปรเจกต์อื่น (เลยเปลี่ยนพอร์ตเริ่มต้นเป็น 3400)
- `<FeedbackHost />` ต้อง mount ครั้งเดียวที่ root layout (ทำไว้แล้วใน `src/app/layout.tsx`)
- `Field` ยังมี selector `[data-bank-picker]` ที่เป็นของเฉพาะระบบต้นทาง (ไม่เป็นอันตราย คงไว้ตามโค้ดเดิม)
- `Drawer` ในต้นทางไม่มี `role`/`aria-modal` (ต่างจาก `Dialog`) — **แก้แล้ว** ในหน้าต่างชุดใหม่ (`components/Overlay.tsx`)
- `ImagePicker` แก้จากต้นทาง: รับ `upload(file) => Promise<string>` และ `resolveUrl(value) => string` เป็น props (ต้นทางเรียก endpoint อัปโหลดของระบบอบรมตรงๆ)
- `tailwind.config.ts` เพิ่ม `opacity: { 8: "0.08" }` — **ต้นทางมีบั๊ก:** ใช้ `bg-ink/8`, `border-ink/8` ฯลฯ ราว 46 จุด (Skeleton, Chip mute, ราง Progress, StatusBadge not_started, เส้นแถวตาราง) แต่สเกล opacity ของ Tailwind ไม่มี 8 คลาสเหล่านั้นเลยไม่ถูกสร้างและมองไม่เห็นในต้นทางด้วย ที่นี่แก้แล้ว
- **กราฟ (ดู `/dashboard`):** ใช้ Recharts แต่หน้าตาตามสกิล dataviz — เส้น 2px, แท่งบาง ≤24px ปลายโค้ง 4px, กริดเส้นทึบบางเฉียบ, ตัวหนังสือใช้สีข้อความ, tooltip รวมทุกซีรีส์ + เส้นแนวตั้ง, legend กดซ่อน/แสดงได้โดยสีไม่เปลี่ยน, ทุกกราฟมีปุ่ม "ตาราง" เป็นฝาแฝดที่เข้าถึงได้
- **สีกราฟตามสี CI:** ช่อง 1–3 = สีหลัก/รอง/ตกแต่ง บีบเข้าเกณฑ์ความสว่าง/ความสด และปรับความสว่างอัตโนมัติจนคู่ที่อยู่ติดกันผ่านเกณฑ์ตาบอดสี (ΔE ≥ 8 / ตาปกติ ≥ 15) ทั้งโหมดสว่าง/มืด · ช่อง 4–8 = **สร้างจากชุดสี CI เอง** (เลือกเฉดที่ห่างจากสี CI มากที่สุดบนวงล้อสี ความสดระดับเดียวกับสี CI จึงไม่สดโดดออกนอกชุด · เฉดคงที่ชุดแรกที่ลองสดเกินจนดูเป็นคนนอกเมื่อชุดสีแบรนด์นุ่ม) ลองทุกลำดับ/ระยะสลับความสว่างแล้วเลือกชุดที่คู่ติดกันแยกง่ายสุด · ตรวจกับสีหลัก 11 ชุดแล้วผ่านทั้งหมด (`tests/chart-palette.test.ts`) · สีอำพันและมิ้นต์คอนทราสต์กับพื้นขาวต่ำกว่า 3:1 จึงต้องมี label ตรงๆ หรือตารางข้อมูลช่วยอ่านเสมอ (กราฟทุกตัวมีปุ่มตาราง)
- **ข้อจำกัดของกราฟ:** donut ใช้ได้ดีเมื่อไม่เกิน ~6 ชิ้น (ที่เกินรวมเป็น "อื่นๆ") · ซีรีส์เกิน 8 ให้รวมเป็น "อื่นๆ" หรือแยกเป็นหลายกราฟ ไม่ใช้สีเพิ่ม · ไม่มีกราฟสองแกน Y โดยตั้งใจ (ตีความผิดง่าย)
- **สี CI ใช้ร่วมกันทั้งแอป:** ค่าอยู่ใน store กลาง `lib/ci-store.ts` (จำใน localStorage · แท็บอื่นเปลี่ยนก็ตาม) · `<CiThemeApplier/>` ที่ root layout เป็นตัวทาสีให้ทุกหน้า ส่วน `<CiPanel/>` เป็นแค่ตัวแก้ค่า วางกี่หน้าก็ได้ · สคริปต์ใน `<head>` (`lib/ci-script.ts`) ทาสีที่คำนวณไว้ก่อน React โหลด ไม่เห็นสีตั้งต้นกระพริบ · โปรเจกต์อื่นที่ย้ายไปใช้ตั้งสีตายตัวได้โดยไม่ต้องมี store: เรียก `ciTheme()` + `chartThemeCss()` ตรงๆ
- **CalendarHeatmap (`lib/calendar-heatmap.ts` + `charts/CalendarHeatmap.tsx`):** ตรรกะปฏิทิน/streak เป็นฟังก์ชันล้วนมีเทสต์ (`tests/calendar-heatmap.test.ts`) · สี 5 ระดับเฉดเดียวจากสีหลัก (ตามสี CI) · ช่องก่อน/หลังช่วงข้อมูลเป็นช่องว่าง ต่างจากวันที่ไม่มีกิจกรรม · ป้ายเดือนที่สัปดาห์มีวันที่ 1 (ตัดเดือนแรกที่ไม่เต็มถ้าชนกัน) · วันที่ปี พ.ศ. ในภาษาไทย · คีย์บอร์ดลูกศร/Home/End (โฟกัสทีละช่อง) · จอแคบเลื่อนแนวนอนและเริ่มที่ช่วงล่าสุด · ส่งตารางแทนผ่าน `calendarTable()` · streak ปัจจุบัน: ถ้าวันสุดท้ายยังว่าง (วันนี้ยังไม่ทำ) นับถอยจากเมื่อวาน ไม่ถือว่าขาด · **ยังไม่มีโหมด 3D**
- **DateRangePicker (`components/DateRangePicker.tsx` + `lib/calendar-range.ts`):** ตัวเลือกช่วงวันที่ต่อยอดจาก DatePicker · ค่าเป็น `{ from, to }` ISO (ค.ศ.) แสดงปี พ.ศ. ในภาษาไทย (ป้ายย่อ "12 – 18 ต.ค. 2569") · คลิกแรกวันเริ่ม คลิกสองวันสิ้นสุด (คลิกย้อนได้ ระบบเรียงให้) มีตัวอย่างช่วงขณะชี้ · ค่าสำเร็จรูป วันนี้/7/30/90 วัน/เดือนนี้/เดือนก่อน (`presets` true/false/เลือกเอง) · จอกว้าง 2 เดือน จอแคบ 1 เดือน + ชิปค่าสำเร็จรูป · `min`/`max`/`maxDays` · คีย์บอร์ดครบ (Esc ขณะรอวันสิ้นสุด = ยกเลิกการเลือก ค่าเดิมไม่เปลี่ยน) · `onChange` ถูกเรียกเมื่อเลือกวันสิ้นสุดแล้วเท่านั้น · ตรรกะเป็นฟังก์ชันล้วนมีเทสต์ (`tests/calendar-range.test.ts`) · **ยังไม่ได้ต่อกับตัวกรองในหน้า /dashboard** (ตัวกรองหน้านั้นยังเป็นแท็บ 7/30/90 วัน)
- **Combobox (`components/Combobox.tsx` + `lib/combobox.ts`):** ค้นหา + เลือกอันเดียวหรือหลายอัน (`multiple`) · พิมพ์กรองแบบไม่สนตัวพิมพ์/เครื่องหมายกำกับ (cafe หา Café เจอ) หลายคำต้องเจอครบ ค้นเจอจาก `keywords`/`description` ด้วย ตัวอักษรที่ค้นเจอถูกไฮไลต์ (รองรับภาษาไทยรวมสระอำ และอีโมจิ) · โหมดหลายอัน: เลือกแล้วเป็นชิป ลบทีละอันหรือกด Backspace ตอนช่องค้นหาว่าง เลือกต่อเนื่องได้โดยแผงไม่ปิด `maxSelected` จำกัดจำนวน ชิปยุบเป็น "+N" ตอนไม่ได้โฟกัส (`maxVisibleChips`) · `onCreate` ให้พิมพ์เพิ่มตัวเลือกใหม่ได้ (ไม่เสนอเมื่อซ้ำของเดิม) · ↑↓ ข้ามรายการที่ปิด (`disabled`) · Esc ล้างคำค้นก่อนแล้วค่อยปิด ไม่ลามไปปิด dialog · ARIA combobox/listbox ครบ · ใช้กับ `Field` (error กรอบแดง) ได้ · ตรรกะเป็นฟังก์ชันล้วนมีเทสต์ (`tests/combobox.test.ts`) · ไม่มี virtualization (ไม่เหมาะกับรายการเป็นหมื่น)
- **Carousel (`components/Carousel.tsx`):** ลาก/ปัดได้ด้วยนิ้วหรือเมาส์ ปล่อยแล้ว snap ด้วยสปริงนุ่ม (framer-motion) · ปัดเร็วแม้ระยะสั้นก็ไปใบถัดไป · `perView` เป็นตัวเลขหรือตามความกว้างกล่อง (`{ 0: 1, 520: 2, 860: 3 }`) ไม่เหลือช่องว่างท้ายแถว · `loop` วนไม่รู้จบแบบไร้รอยต่อ (มีใบสำเนาที่หัว/ท้าย ใบสุดท้าย → ใบแรกเลื่อนต่อไปทางเดิม ไม่กรอย้อนกลับ · ลากเลยขอบได้ทั้งสองทาง) · `autoplay` (ms) พร้อมแถบเวลาในจุดที่เลือก หยุดเองเมื่อชี้/โฟกัส/ลาก/สลับแท็บ (เอาปุ่มหยุด/เล่นออกตามที่ขอ — ดูหมายเหตุ WCAG ด้านล่าง) · ใส่คลาส `kenburns` ที่รูป = ซูมออกช้าๆ ตอนใบนั้นถูกเลือก · `data-caption` = คำบรรยายเลื่อนขึ้น · คีย์บอร์ด ← → · ใบนอกจอ `inert` · ลากแล้วปล่อยบนลิงก์ไม่ถือเป็นคลิก · ลูกศรซ่อนบนจอเล็ก · ลดการเคลื่อนไหว = เปลี่ยนใบทันที ไม่เลื่อนเอง
- **Marquee (`components/Marquee.tsx`):** แถบวนไม่รู้จบด้วย CSS transform (ลื่นแบบ GPU ไม่มีรอยต่อ) · ความเร็วเป็น px/วินาที (เนื้อหายาวขึ้นไม่เร็วขึ้น) · ซ้าย/ขวา/ขึ้น/ลง · ชี้หรือโฟกัสแล้วหยุด · ขอบจางหาย · ชุดที่วาดซ้ำซ่อนจาก screen reader · ลดการเคลื่อนไหว = ไม่เลื่อน เลื่อนดูเองได้ · ตรรกะคำนวณ (snap หลังลาก, จำนวนใบต่อหน้า, จำนวนชุดที่ต้องซ้ำ, ระยะเวลา) อยู่ใน `lib/carousel.ts` มีเทสต์
- **รูปตัวอย่างใน Gallery:** มาจาก Lorem Picsum (ภาพจาก Unsplash ใช้ฟรีตามสัญญาอนุญาตของ Unsplash) แสดงจาก URL ตรงๆ ไม่ได้เก็บไว้ในโปรเจกต์ (ต้องต่ออินเทอร์เน็ตถึงจะเห็นรูป) มีเครดิตช่างภาพในแต่ละรูป
- **ฟอร์มพื้นฐาน (ชุด 1)**: ตรรกะล้วนอยู่ใน `lib/slider.ts`, `lib/number-input.ts`, `lib/file-drop.ts` และมีเทสต์ใน `tests/form-controls.test.ts`
  - **Checkbox / Radio / RadioGroup / Switch (`components/Choice.tsx`)**
    - ใช้ `<input>` จริงซ่อนไว้ใต้หน้าตาที่วาดเอง จึงส่งค่าในฟอร์มได้ ส่วนคีย์บอร์ดและ screen reader ทำงานแบบ native
    - Checkbox: ติ๊กแล้วเครื่องหมายถูกวาดเป็นเส้น มี `indeterminate` (ขีดกลาง, `aria-checked="mixed"`) ไว้ทำช่อง "เลือกทั้งหมด"
    - RadioGroup: มี `variant="list" | "card"` (การ์ดคลิกได้ทั้งใบ)
    - Switch: เป็น `role="switch"` ปุ่มกลมเลื่อนแบบเด้งและยืดออกตอนกดค้าง ใช้กับค่าที่มีผลทันที ถ้าต้องกดบันทึกก่อนให้ใช้ Checkbox
    - ทุกตัวมี `size="sm" | "md"` และ `description`
    - **ข้อควรระวัง:** ถ้าครอบด้วย `Field` ต้องใช้ `as="div"` ไม่งั้นจะเป็น label ซ้อน label
  - **SegmentedControl:**
    - พื้นของตัวที่เลือกเลื่อนตามแบบสปริง
    - เป็น ARIA radiogroup (ลูกศรเลื่อนและเลือกได้ ข้ามตัวที่ปิด วนรอบ)
    - `fullWidth` ยืดเต็มกล่อง และไม่ตัดคำบนจอแคบก่อนจำเป็น
    - ใส่ไอคอนอย่างเดียวได้ (ต้องมี `aria-label`)
  - **Slider (`range` = สองปุ่ม):**
    - ลากปุ่มหรือคลิกที่รางได้ โหมดช่วงสองปุ่มไม่ข้ามกัน และกำหนดระยะห่างขั้นต่ำได้ด้วย `minGap`
    - คีย์บอร์ดตาม ARIA: ลูกศร, Shift/PageUp/PageDown, Home/End
    - ป้ายค่าลอยเหนือปุ่ม (`tooltip`) และ `marks` พร้อมป้าย
    - `format` ใช้ทั้งกับป้ายและ `aria-valuetext`
    - `onCommit` ถูกเรียกตอนปล่อยปุ่มเท่านั้น ใช้ยิง API ได้
    - ค่าที่ได้ปัดลงขั้นแล้ว ไม่มีเศษทศนิยมลอย
  - **NumberInput:**
    - ใส่ comma ให้เอง และรับเลขไทยได้
    - ปุ่ม +/− กดค้างแล้ววิ่งเร็วขึ้นเรื่อยๆ ใช้ ↑↓ ได้ (Shift = ×10)
    - `min`/`max`/`step`/`precision`/`prefix`/`suffix`
    - ลบจนว่างได้ (ค่าเป็น `null` ไม่กลายเป็น 0)
    - ใช้ `type="text"` + `inputMode` แทน `type="number"`: ล้อเมาส์จะไม่เปลี่ยนค่า และพิมพ์ "e" ไม่ได้
    - ระหว่างพิมพ์ยังไม่บีบค่า ออกจากช่องหรือกด Enter แล้วค่อยจัดรูปแบบและบีบให้อยู่ในช่วง
  - **FileDrop:**
    - ลากวางหรือกดเลือกได้หลายไฟล์ มีแถบความคืบหน้ารายไฟล์ และปุ่มยกเลิก/ลองใหม่/ลบ
    - รูปภาพมีภาพย่อ ไฟล์อื่นมีไอคอนตามชนิด
    - ตรวจ `accept`/`maxSize`/`maxFiles` ก่อนอัปโหลด และแจ้งเป็นรายไฟล์
    - ผูกระบบอัปโหลดผ่าน `upload(file, { onProgress, signal })`
      - ถ้าใช้ `fetch` จะไม่มีความคืบหน้าระหว่างอัปโหลด ต้องใช้ XHR ที่มี `upload.onprogress` แทน
