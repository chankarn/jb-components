### `MediaLightbox`

MediaLightbox: ดูรูป/วิดีโอเต็มจอ ทีละรายการหรือเป็นชุด
- เลื่อนดู: ปุ่ม ‹ › · ← → · ปัดซ้าย/ขวา (รูป) · แถบภาพย่อด้านล่าง · เปลี่ยนรายการแล้วเลื่อนเข้าตามทิศ
- รูป: คลิก/ดับเบิลคลิกหรือปุ่ม 🔍 ซูม 2.5 เท่า แล้วลากดูส่วนต่างๆ · Esc ครั้งแรกออกจากซูม ครั้งที่สองปิด
- วิดีโอ: เล่นเองพร้อมปุ่มควบคุมของเบราว์เซอร์ · เปลี่ยนรายการแล้วหยุดเอง · ใช้กับไฟล์ที่เพิ่งเลือกจากเครื่องได้ (URL.createObjectURL)
- ปุ่มเปิดไฟล์ต้นฉบับในแท็บใหม่ · โหลดรูปข้างเคียงไว้ก่อน (เลื่อนแล้วไม่ต้องรอ) · โหลดไม่ได้ → แจ้งในหน้าต่าง
- พฤติกรรมหน้าต่างเดียวกับ Dialog: ล็อกการเลื่อน · กัน Tab หลุด · ปิดแล้วคืนโฟกัส · ประกาศ "รายการที่ n จาก N"

### type `MediaItem`

```ts
type MediaItem = {
  src: string;
  /** 'image' | 'video' หรือ MIME ของไฟล์ (เช่น 'video/mp4' จากไฟล์ที่อัปโหลด) · ไม่ระบุ = ดูจากนามสกุล */
  type?: string;
  title?: string;
  /** ข้อความแทนรูป (ไม่ระบุ = ใช้ title) */
  alt?: string;
  /** ภาพปกของวิดีโอ (ไม่ระบุ = ใช้เฟรมแรกของคลิป) */
  poster?: string;
  /** เครดิต/บรรทัดรองใต้ชื่อ */
  credit?: string;
};
```

### `Carousel`

Carousel: ลาก/ปัดได้ (นิ้ว/เมาส์) ปล่อยแล้ว snap ด้วยสปริงนุ่ม · ปุ่มก่อน/ถัดไป · จุดบอกตำแหน่ง (จุดที่เลือกยืดเป็นแคปซูล และมีแถบเวลาเมื่อเลื่อนเอง)
- หลายใบต่อหน้าได้ตามความกว้าง "ของกล่องเอง" (ใช้ในการ์ดแคบหรือกว้างก็ถูก) · ไม่เหลือช่องว่างท้ายแถว
- `loop`: วาดใบสำเนาไว้หัวและท้าย เลื่อนเลยใบสุดท้ายไปบนสำเนาของใบแรก แล้วสลับไปใบจริงเงียบๆ ตอนหยุด (หน้าตาเหมือนกันจึงไม่เห็นรอยต่อ)
- autoplay หยุดเองเมื่อชี้/โฟกัส/ลาก/สลับไปแท็บอื่น
- ปุ่มลูกศรซ่อนบนจอเล็ก (ปัดนิ้วแทน · ไม่ทับคำบรรยายบนภาพที่เตี้ยลง) · คีย์บอร์ด: โฟกัสที่ carousel แล้วใช้ ← → · ใบที่อยู่นอกจอถูกซ่อนจาก screen reader และกด Tab เข้าไม่ได้ (inert)
- ลากแล้วปล่อยบนลิงก์ไม่ถือเป็นคลิก · ผู้ใช้ตั้งลดการเคลื่อนไหว = เปลี่ยนใบทันทีและไม่เลื่อนเอง
- ใส่คลาส `kenburns` ที่รูป = ซูมออกช้าๆ ตอนใบนั้นถูกเลือก · ใส่ `data-caption` = ค่อยๆ เลื่อนขึ้นมา (CSS ใน globals.css)


| prop | ชนิด | ค่าตั้งต้น | คำอธิบาย |
|---|---|---|---|
| `children` **(จำเป็น)** | `ReactNode` |  | สไลด์แต่ละใบ (children แต่ละตัว = 1 ใบ) |
| `perView` | `PerView` | `1` | จำนวนใบต่อหน้า: ตัวเลข หรือตามความกว้างกล่อง `{ 0: 1, 640: 2, 1024: 3 }` |
| `gap` | `number` | `16` | ช่องไฟระหว่างใบ (px) |

| `autoplay` | `number \| false` | `false` | เลื่อนเองทุกกี่มิลลิวินาที (false = ไม่เลื่อนเอง) · หยุดเมื่อชี้/โฟกัส/ลาก/สลับแท็บ/ผู้ใช้ตั้งลดการเคลื่อนไหว |

### `Marquee`

Marquee: แถบเลื่อนวนไม่รู้จบ (โลโก้ ข่าวสั้น รูป รีวิว)
- วาดเนื้อหาซ้ำพอให้ยาวกว่ากล่อง แล้วเลื่อนไปหนึ่งชุดพอดีด้วย CSS transform (ลื่นแบบ GPU ไม่กระตุก ไม่มีรอยต่อ)
- ความเร็วเป็น px/วินาที: เนื้อหายาวขึ้นก็ไม่เร็วขึ้น · วัดขนาดใหม่เองเมื่อกล่อง/ฟอนต์/รูปเปลี่ยน
- ชี้หรือโฟกัสแล้วหยุด (`pauseOnHover`) · ขอบจางหาย (`fade`) · แนวนอนหรือแนวตั้ง กลับทิศได้
- ชุดที่วาดซ้ำถูกซ่อนจาก screen reader และกด Tab เข้าไม่ได้ (อ่านแค่ชุดเดียว)
- ผู้ใช้ตั้งลดการเคลื่อนไหวในระบบ → ไม่เลื่อน แสดงชุดเดียวที่เลื่อนดูเองได้


| prop | ชนิด | ค่าตั้งต้น | คำอธิบาย |
|---|---|---|---|
| `children` **(จำเป็น)** | `ReactNode` |  |  |
| `speed` | `number` | `40` | ความเร็ว px ต่อวินาที (คงที่ไม่ว่าเนื้อหาจะยาวแค่ไหน) |
| `direction` | `"right" \| "left" \| "up" \| "down"` | `'left'` |  |
| `gap` | `number` | `24` | ช่องไฟระหว่างชิ้น (px) |
| `pauseOnHover` | `boolean` | `true` |  |
| `fade` | `boolean` | `true` | ขอบสองข้างจางหาย |
| `label` | `string` |  | ชื่อสำหรับ screen reader (เช่น "พันธมิตรของเรา") |
| `className` | `string` |  | แนวตั้งต้องกำหนดความสูงผ่าน className เช่น `h-80` |
